# Illustrations

Views of the Eurasian curlew the app is named after, kept as standalone artwork: for the README,
and for places in the app where a picture does more than a label — empty states, the About
dialog, onboarding.

These are **not** icons. The app icon lives in
[`../icons/hicolor/scalable/apps/eu.jumplink.curlew.svg`](../icons/hicolor/scalable/apps/eu.jumplink.curlew.svg)
and must not be replaced by one of these: it is the only one drawn to the GNOME icon grid and to
the messenger-bubble shape that Fractal and Flare share. Everything here has a transparent
background and a `viewBox` cropped to the drawing, so it scales to whatever box it is dropped in.

| File | View | From |
|---|---|---|
| [`curlew-wading.svg`](curlew-wading.svg) | The bird standing in a tide pool, side view, with a ripple where its legs break the surface | Round 1, variant A |
| [`curlew-orange.svg`](curlew-orange.svg) | The same bird as a flat graphic in a bold orange, no scene | Round 1, variant B |
| [`curlew-standing.svg`](curlew-standing.svg) | The whole bird upright on the mudflat, side view, with the scalloped folded wing | Round 2, candidate C1 |
| [`curlew-probing.svg`](curlew-probing.svg) | Leaning forward in three-quarter view, bill driven into the sand | Round 2, candidate C2 |
| [`curlew-portrait.svg`](curlew-portrait.svg) | Head-and-neck crop, the bill as one long diagonal | Round 2, candidate C3 |
| [`curlew-calling.svg`](curlew-calling.svg) | Head thrown back, bill raised and open — the call the app is named for | Round 2, candidate C5 |
| [`curlew-silhouette.svg`](curlew-silhouette.svg) | Flat single-colour silhouette, tintable, readable at any size | Round 2, candidate C7 |
| [`curlew-front.svg`](curlew-front.svg) | Facing the viewer square on, both eyes, bill swinging out across the breast | Round 4, variant V7 |
| [`curlew-front-quarter.svg`](curlew-front-quarter.svg) | The same bird a few degrees off square, which shows more of the bill's curve | Round 4, variant V8 |

Where a source carried a messenger bubble, a dusk disc or sound arcs, those are gone — only the
bird is left, with its own ground where it has one. The reasoning behind each round, and the
candidates that were not kept, is in
[`../../../docs/design/app-icon/README.md`](../../../docs/design/app-icon/README.md).
