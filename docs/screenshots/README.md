# Screenshots

Generated by `dev/screenshots.sh` from the demo mode (`CURLEW_DEMO=1`, data in
`app/src/core/demo/`), headless, window alone with its shadow, light and dark, English and German.
Never edit by hand; rerun the script (`dev/screenshots.sh --build`, see `docs/design/ui.md`).

File name: `<motif>.<lang>.<scheme>.png`.

## For the metainfo (Flathub)

All windows are ≤ 900×740 logical. The files keep the window shadow (a 900×640 window is a 932×672
canvas), so **every wide motif is 900×640 and no file exceeds 1000×700**; the phone-width motifs
(360×740) are not suggested for the wide slots. Cropping the shadow was rejected: the shadow is part
of how the window looks on a GNOME desktop and Flathub only bounds the size. Use the English file first, the German one with `xml:lang="de"`;
captions are one sentence without a full stop. Suggested set, light scheme:

1. `conversations.en.light.png` (default) with `conversations.de.light.png` (`de`)
2. `conversation.en.light.png` / `.de.light.png`
3. `contact.en.light.png` / `.de.light.png`
4. `accounts.en.light.png` / `.de.light.png`
5. `conversation-narrow.en.light.png` / `.de.light.png` (mobile)

`welcome-delta-chat` and `email-chat` stay out of the metainfo for now: they would promise Delta
Chat compatibility, which waits for the live test against a real Delta Chat peer. Dark variants
(`*.dark.png`) can be added as `<image type="source" …>` with a `color-scheme` hint.

Every file the README, the guides or the metainfo point to must exist: `dev/check-screenshot-refs.sh`
checks that (it runs in CI). `dev/screenshots.sh --check` checks the full set of generated files.
